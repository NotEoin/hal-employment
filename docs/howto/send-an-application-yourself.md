# Send an application yourself

Some job sites ask for an account, a test or a form Hal cannot fill in. You can still use the CV, letter and
answers Hal made and approved with you: they are kept in Documents, one folder per application.

Hal never presses Submit and never sends anything to an employer. You always send it.

1. Open **Documents** from the menu on the left.
2. Under **By application**, pick the job. The files on the right are exactly what you approved.
3. Upload the CV and the cover letter to the employer's site: press **Download** next to each, then choose
   the downloaded file on the site. **Download all** gives you every file in one zip.
4. For the form's questions, press **Copy all** next to "Answers to the form's questions" and paste each
   answer into its box. **Copy text** next to the cover letter is for sites that want the letter typed in.
5. For your name, email, phone, degree and similar boxes, open the **Copy-paste details** tab and press
   **Copy** next to each one.
6. Read the form through on the employer's site, then press Submit there yourself.
7. Back in Documents, press **I sent it myself**, so Hal moves the application to Sent and watches your
   email for a reply.

On the computer Hal runs on, **Open the folder** shows the same files in your file manager. The folder is
named after the application's number, the employer and the job, for example:

```text
Documents/Hal Employment/Applications/0412 Civic Insight - Junior Researcher   # on Linux
Documents\Hal Employment\Applications\0412 Civic Insight - Junior Researcher   # on Windows
```

| Symptom | Fix |
| --- | --- |
| The application is not in the list | Hal has not made its documents yet. Open the job and press Apply with Hal, or search for it in the box at the top of Documents. |
| "Open the folder" is missing | You are using Hal from another computer. Use **Download all** instead; the files come to the computer you are on. |
| "Hal could not reach the clipboard" | Your browser blocked copying. Select the words on the page and copy them with Ctrl C (Cmd C on a Mac). |
| Home says "Documents for ... need making again" | An older job used the same folder before Hal numbered them. Press **Make documents again** on Home, then approve them as usual. |
| A copy-paste detail is missing | Add it in Settings, You. Private answers (equality and adjustment questions) are never shown here. |
| The site wants a Word file | Ask Hal for one from My CV once Word export is available; until then, most sites also accept the PDF. |
