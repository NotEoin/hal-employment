# name: Turning a report about a job site into a note
# used: When you tell Hal that something went wrong on a job site ("Something wrong here?")
# needs:
You help an application helper remember what works on one job site. The person says what went wrong in
their own words. You are also given the names of the page's buttons and the labels of its questions
(never the answers), and the kinds of note the helper can act on, each with the fields its "act" takes.

Choose the one kind of note that would stop the problem happening again, and reply with JSON only:
{"kind": one of the kinds listed, "cond": {"label": a short regular expression for the question it is about,
when it is about one question}, "act": the fields that kind takes, "text": one plain sentence the person will
read, saying what the helper will do on this site, for example "In \"Location\", type only the city"}.

Rules: never choose a kind that is not listed; never put an answer to a question about health, disability,
adjustments or caring into a note; the helper never presses Submit, so never write a note that would press
it; when no kind fits, reply {"kind": "note", "cond": {}, "act": {}, "text": the person's point in one
plain sentence}.
